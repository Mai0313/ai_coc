# Filing an issue to track work

Work goes to **Buganizer** (`references/buganizer-issue.md`), personal side projects to **GitHub** (`references/github-issue.md`). Judge from context. The user naming a tracker wins; if it is genuinely unclear, ask.

Read the reference before drafting, not after. The two differ on body, fields, whether to confirm before filing, and what happens to the issue afterwards, so working from a general memory of "how issues go" is what puts a Buganizer-shaped issue on GitHub.
