# 打資源順便花掉

打到滿 → 花掉 → 回去打, 繞到花不掉為止. 他交辦時講了要花 (「打完順便刷牆」「把資源花掉」「打資源跟升級牆壁」) 才是這一趟, 不是你判斷出來的. 每一趟打資源照 `references/farming.md` 派, subagent 打到 `stock_full` 回報, 你花完再派下一趟, 同一份交辦. 回報說它在半路停手, 就照那份回報處理, 不要再派: 那些停手的理由換一個 subagent 一樣成立, 使用者在手機上玩的話, 每派一個就把他踢下線一次. 背景那輪跑完就自己接下一步, 不要回頭問; 中間不要拖: 打滿的村莊是別人最想打的, 趕快花掉是唯一減少暴露的動作.

**第一步是問 `ai_coc world`, 沒有例外.** 面板上列的是遊戲停著那一邊的建築跟牆, 站錯村莊花的就是另一邊的倉庫. 要花主村的先 `world --day`. **夜世界打滿了就換去打日世界**, 兩邊倉庫不相通; 夜世界的建築跟牆一樣走 `upgrades` 的面板. 兩個世界都滿了才通知他. **底下講的都是日世界.**

**一, 授權.** 閒著的工人、實驗室、戰寵小屋照 `upgrades` 的「沒人指名時挑哪一件」挑 (英雄、研究、戰寵都在裡面), 城牆照 `upgrades` 的「城牆」刷, 都不用問. **建築跟牆都要有工人閒著** (`status` 那個世界那一行的「工人 閒/總」說真的有, 只有遊戲停著那個世界有這一行): 倉庫滿了而工人發呆, 資源被丟掉, 工人也沒蓋東西.

**二, 順序: 牆先刷, 建築後升**, 刷之前先把建築要的那一筆留下來 (`upgrades` 的「城牆」講怎麼留; 循環刷牆的那一圈不留, 因為它不升建築). 兩個搶同一個工人, 而升建築會把閒著的工人派去蓋好幾天, 先升建築, 刷牆就只會撞「所有建築工人都在忙碌中」.

**三, 兩個出口關掉的方式不一樣.** 牆需要有一個工人閒著, `0/N` 一片都買不了, 這一種升建築也接不上. 牆被大本營的等級卡住 (面板上沒有城牆那一列, 或者 `confirm --pay` 回 `no_confirmation` 而圖上是確認鈕灰掉的視窗), 正是升建築該接手的地方, 工人還閒著; 撞到一次這一趟就不用再刷牆.

**停手的條件是「資源花不掉了」**: 工人全忙, 或者工人閒著而沒有能升的建築、牆也刷不動 (滿級或被大本營卡住). **刷到升級鈕變紅字不是花不掉**: 是倉庫花到買不起下一批了, 回去打. **他要的是一直刷牆 (「循環刷牆到我說停」「刷牆刷到早上」) 而工人閒著, 這一圈就幾乎不會自己停. 這一圈刷完牆不升建築**, 除非是牆到頂了: 升建築會把閒著的工人派出去, 下一圈刷牆就撞工人全忙, 圈也就斷了.

**黑水只有升英雄能消化.** 英雄在表上都升著或都滿級, 黑水就停在那裡, 回報要講出來.
